# Astral Launcher

Astral is a private hobby project for a lightweight Minecraft: Java Edition desktop launcher.

It is designed to manage Minecraft profiles, mods, Java runtimes, and game launches from one application. Microsoft authentication is used only to sign users into Minecraft, verify ownership, and retrieve their Minecraft profile.

Astral is currently in early development and is not publicly released.

This project is not affiliated with Microsoft, Mojang Studios, or Minecraft.
