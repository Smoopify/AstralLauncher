# Privacy Policy

Astral uses Microsoft's OAuth device-code flow and never asks for a Microsoft password.

Authentication data is used only to sign in to Xbox Live and Minecraft services, verify Minecraft: Java Edition ownership, retrieve the Minecraft profile, and launch the game. Tokens are stored locally using the operating system's secure credential storage where available. Astral does not sell or share personal data.

This is a private hobby project and is not affiliated with Microsoft, Mojang Studios, or Minecraft.
